# 🤖 AI Projects

This repository contains a collection of **beginner-level Artificial Intelligence and Python projects** designed to help understand core AI concepts and basic problem-solving techniques.  
The projects focus on logic building, algorithm implementation, and introductory machine learning ideas using Python.

---

## 📖 Project Overview

The **AI Projects** repository is created as a learning space for experimenting with small AI-based programs.  
Each project demonstrates a specific concept such as chatbot logic, recommendation systems, or game-based decision making.

These projects are ideal for students and beginners who want hands-on experience with Python and Artificial Intelligence fundamentals.

---

## 🚀 Included Projects

### 🗣️ Chatbot
A simple rule-based chatbot implemented in Python that responds to user input based on predefined logic.

### 🎯 Recommendation System
A basic recommendation system that suggests items using simple logical or data-based approaches.

### ❌⭕ Tic Tac Toe Game
A Python-based Tic Tac Toe game demonstrating game logic, decision-making, and control flow.

## 🛠️ Tech Stack

- **Language:** Python  
- **Concepts:** Artificial Intelligence, Logic Building, Game Algorithms  
- **Level:** Beginner
